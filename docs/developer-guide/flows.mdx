# Request and startup flows

These maps show how analyst clicks become SQL and JSON, and what happens when
the API process starts. They replace GitHub-only Mermaid for the docs portal.
Product screenshots stay on the user guide.

The migrated [system design](./system-design.md) page embeds the same artifacts
next to each flow description (CommonMark iframes, reapplied after weekly
sync). Use this page when you want the interactive maps without scrolling the
full design document.
